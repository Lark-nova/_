Security Recommendations

Follow these practices when handling credentials.

  • Rotate keys regularly
  • Never expose keys in frontend code
  • Use environment variables
  • Restrict production access
  • Monitor unusual activity

Quick Start

Authenticate with your secret key using an official SDK.

from lark import Lark

client = Lark(
    api_key="LARK_API_KEY"
)

response = client.chat.create(
    model="nova-apex",
    messages=[{"role": "user", "content": "Hello"}]
)
import Lark from "@lark/sdk"

const client = new Lark({
  apiKey: process.env.LARK_API_KEY
})

const response = await client.chat.create({
  model: "nova-apex",
  messages: [{ role: "user", content: "Hello" }]
})
